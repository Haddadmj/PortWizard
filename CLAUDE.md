# PortWizard

A macOS menu-bar app that shows which ports are open and which application owns
each one. Swift 6 package, macOS 14+, built with SwiftPM.

## Agent skills

### Issue tracker

Issues live as GitHub issues on `Haddadmj/PortWizard`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
